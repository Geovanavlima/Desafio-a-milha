 Desafio 14 - A Milhar 

Simulação de uma máquina de jogo do bicho (estilo "milhar"), desenvolvida em Python como projeto final da disciplina de Programação.

 Sobre o desafio

O programa sorteia 4 números aleatórios entre 0 e 9 a cada tentativa. O jogador vence quando os 4 números sorteados são iguais entre si. O jogo repete as tentativas automaticamente até que a vitória aconteça, exibindo o número de cada tentativa (formatado como 001, 002, 003...) e o resultado sorteado.

 Como executar

1. Certifique-se de ter o Python 3.10 ou superior instalado
2. Clone este repositório ou baixe o arquivo `desafio14_a_milhar.py`
3. No terminal, rode:

```bash
python desafio14_a_milhar.py
```

Conceitos aplicados

- Laços de repetição (`while`) para repetir as tentativas até a vitória
- Módulo `random` para sortear números aleatórios
- Sets para verificar de forma eficiente se todos os números sorteados são iguais
- Funções organizadas por responsabilidade única (sortear, verificar vitória, formatar, exibir resultado)
- Dataclasses e type hints para deixar o código mais legível e organizado
- f-strings e formatação de números** (zeros à esquerda)

 O que aprendi

Este projeto foi minha primeira experiência estruturando um programa em Python com funções separadas por responsabilidade, em vez de escrever tudo em um único bloco de código. Também aprendi a usar o Git e o GitHub na prática, desde a criação do repositório até o commit e push das alterações.
